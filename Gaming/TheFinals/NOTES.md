# The Finals — detection notes

**Approximate.** The Finals has no clean per-player kill callout in the HUD; personal
elimination text is rare/garbled in OCR. Kills here are a **best-effort proxy** from the
top-right **kill feed** (`ELIMINATED BY | <killer>`), so the count reflects eliminations
*shown in the feed* (all players), not strictly the streamer's kills.

Death uses the dedicated `DeathBanner` crop; victory uses the `endGame` crop. The core
mode mechanic is `CASHOUT` (objective), which dominates the HUD.
